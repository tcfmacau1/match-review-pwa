# match-review-pwa

## v4.1.0

- 修正過關投注流程：投注單不再要求輸入單場主客隊。
- 每張過關投注可加入 2–8 場賽事，每場獨立選擇運動、聯賽、球隊、玩法、賠率及賽果。
- 支援混合運動、二串一、三串一及三串四，並防止新投注單重複加入同一場。

## v4.0.0

賽事覆盤工作台：支援 iPhone PWA、離線使用、過關投注、半場結算及多平台 AI 預估。

- 按運動及聯賽顯示累積盈虧；過關獨立分類。
- 足球 16 種及籃球 6 種預設玩法，包括角球、首球、下一球、入球總數、半全場及晉級。
- 足球全場按 90 分鐘及補時，籃球全場包含加時。
- 舊記錄保留原有規則；使用設定頁的更新功能套用新版。
