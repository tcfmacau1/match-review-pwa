賽事覆盤工作台 PWA v4.0.0

部署：解壓後，把 index.html、mobile.css、sw.js、manifest.webmanifest 和 icons 資料夾一起上載到同一個 GitHub Pages 目錄，啟用 HTTPS。無需建置、無外部套件或 CDN。
不應只上載 index.html；iPhone「檔案」直接打開 HTML 不支援 PWA 離線安裝。

iPhone：Safari 開啟網站 → 分享 → 加入主畫面 →（如有）開啟「作為網頁 App 開啟」。首次保持連線，設定頁顯示「離線已準備」後，關閉 App、開飛航模式並關閉 Wi-Fi，再由主畫面啟動測試。

舊資料：先在原系統下載 JSON 備份；新網址／主畫面 App 若沒有資料，於設定頁還原 JSON。沿用 matchledger.v1 儲存鍵及 schemaVersion 1，兼容舊備份。示範資料不計入備份。記錄儲存於本機，不會跨裝置同步。清除網站資料或系統回收空間可能遺失記錄，請定期備份至「檔案」或 iCloud Drive。CSV 用於閱讀分析，還原請使用 JSON。

升級：將整套新版覆蓋原部署目錄，保持網址不變。每次發布須更改 sw.js 的 CACHE 版本名稱。新版完成快取後提示更新，先儲存並關閉編輯視窗再套用。不會刪除 localStorage 投注資料。自訂系統名稱不會自動更改 iPhone 已建立的主畫面名稱，可於新增主畫面時自行命名。

本次變更：修正樣式開頭殘留字串；iPhone safe-area、16px 輸入欄及 44px 點按區；手機卡片／表格切換；預設運動、金額及每頁筆數；iOS 分享 JSON；持續儲存申請；離線狀態及新版提示。保留原結算／分析及匯入驗證。


v3 新增：2–8 個選項的過關及系統組合；三串四請加入 3 項並選所有 2 串至 N 串。金額為總額，按分位平均分配各組合，最後總回收四捨五入至分。贏半回收倍率 (十進制賠率+1)/2，輸半 0.5，走盤／取消 1。不適用同場關聯賠率或特殊莊家規則。
全場及上半場比分分別輸入，可選上半場投注結算。比分範圍仍需按實際投注規則選擇。
AI 頁可獨立新增預估；每場最多 30 項，每項可指定 Claude、ChatGPT、Gemini、Perplexity、Grok、Copilot。舊預估保留並標示未標註平台。多項預估逐項計命中率，不推薦、部分命中、走盤及取消排除。純預估不計財務統計。系統不連線 AI 平台。
JSON 備份保留所有選項與預估，可還原舊版記錄。CSV 包含完整記錄 JSON 欄。
驗證：node tests/settlement.cjs；31 項結算、AI、舊資料及備份檢查。另以 DOM 模擬驗證新增、編輯及儲存流程，未在實體 iPhone 驗證。


v4 更新：
1. 運動表現下按聯賽顯示累積盈虧、已結算及待結算筆數、ROI。獨立 AI 預估不計入。過關整張列於投注單所屬運動的過關分類，不拆分或重複歸入各聯賽。
2. 足球 16 種、籃球 6 種預設玩法。升級補齊預設玩法並保留自訂設定；已儲存投注沿用原規則，重新選擇玩法才套用新版規則。
3. 足球全場按 90 分鐘及補時，排除加時及十二碼；籃球全場含加時。上半場玩法使用獨立半場比分。籃球讓分只接受半分盤（例如 -4.5、+2.5），只有全贏或全輸，取消可作廢；大小盤仍按實際盤口結算。
4. 首球及下一球須手動記錄實際入球隊伍，下一球另記錄落盤時點。待確認與已確認無入球分開。
5. 角球使用主客隊全場／半場角球數，與入球比分分開。入球總數支援區間及精確總數，0 球屬雙數。半全場足球 9 選項、籃球 6 選項。
6. 晉級須確認盃賽並填實際晉級隊伍，可依兩回合、加時、十二碼後的賽會結果，不由單場比分推測。
測試：node tests/settlement.cjs 及 node tests/markets.cjs。另以 DOM 模擬測試全部 22 種玩法的表單選取、特殊結果欄位、儲存及過關結算；未在實體 iPhone 驗證。
